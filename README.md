# SWING IT
A simple physics game about swinging a double pendulum. 
Drag the green handle, release it and watch the pendulum move!

## Controls:
- Left click + Drag  = Swing the green handle
- P = Pause
- R = Reset
- W/S = Increase/Decrease simulation speed
- L = apply a random force
- B = Apply braking
- C/H = show controls

Experiment with the pendulum and see what happens!
